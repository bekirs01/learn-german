# Visual mapping

Language-independent illustration IDs for Learn German for Beginners category cards. Replace the PNG, not the ID. Missing files fall back to painted art. Do not put text, letters, logos, or UI in any image.

Shared style: premium editorial still-life, tactile clay/gouache volume, studio light from the upper left, subject large enough to read at ~160px, varied palette (teal, terracotta, plum, sage, ivory). Not a cartoon, not a photo, not beige-on-beige.

Aspect ratio for every category card: **1:1** (2048×2048 preferred).

Work and school phrase categories reuse the word illustrations.

Base path: `assets/images/categories/`.

Home destinations live in `assets/images/home/` (`alphabet.png`, `quiz.png`, `wrong_answers.png`). Same still-life rules: no text, letters, logos, or UI in the image.

Alphabet examples live in `assets/images/alphabet/` (1024×1024). IDs are `alphabet.<stem>` in `language_pack.json`. German teaching words must match the picture: Apfel/apple, Katze/cat, Violine/violin, Computer/computer, Straße/strasse, and so on. Do not keep an English-word still-life after the German example no longer starts with that letter.
